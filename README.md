# Actividad-2.-Juego-de-la-V-bora
Modificación de la lógica para que la comida pueda moverse al azar un paso a la vez, asegurando que se mantenga dentro de los límites de la ventana de juego sin salirse.
Implementación de la selección de colores aleatorios independientes para la víbora y la comida al iniciar cada partida, eligiendo entre una gama de 5 colores diferente.
